# Web文件管理器代码分析


## 文件列表
1. `kebab-case.js` - 前端交互功能
2. `styles.css` - 样式定义
3. `editor.js` - 文件编辑器
4. `main.js` - 核心文件管理
5. `index.php` - 后端处理

## 项目概述
这是一个Web文件管理器，提供类似桌面文件管理器的体验。项目采用**前端JavaScript + 后端PHP**的架构，通过AJAX实现无刷新操作。

## 主要功能模块

### 1. 认证系统
- 用户名/密码登录
- 失败次数限制和锁定
- CSRF Token防护
- Session管理

### 2. 文件管理
- 文件上传（支持拖拽、批量）
- 文件下载
- 文件删除（移入回收站）
- 文件重命名
- 文件移动/复制/粘贴
- 文件搜索（浅层/深度）

### 3. 压缩/解压
- 打包：ZIP、TAR、GZIP、7Z、RAR
- 解压：支持同上格式
- 解压到指定目录（目录树选择）

### 4. 文件编辑
- 集成ACE编辑器
- 支持多种编程语言高亮
- 保存/另存为
- 编码转换

### 5. 回收站
- 删除文件暂存回收站
- 恢复文件到原位置
- 彻底删除
- 自动清理过期文件

### 6. 收藏夹
- 收藏常用文件/目录
- 侧边栏快速访问

### 7. 分享功能
- 生成文件分享链接

### 8. 权限管理
- 修改文件/目录权限（Linux风格）
- 仅Linux系统有效

### 9. 多媒体支持
- 图片预览（支持左右切换）
- 视频播放
- 音乐播放器（播放列表、歌词显示）

### 10. 用户体验优化
- SPA无刷新导航
- 键盘快捷键
- 拖拽操作
- 触摸手势（移动端）
- 进度提示
- Toast通知

## 实现方法分析

### 前端技术栈
- **JavaScript（ES6+）**：核心交互逻辑
- **AJAX（Fetch API）**：与后端通信
- **DOM操作**：动态更新界面
- **本地存储**：保存用户偏好和状态
- **ACE编辑器**：代码编辑功能
- **拖放API**：文件上传和移动
- **History API**：SPA路由

### 后端技术栈
- **PHP（原生）**：后端逻辑处理
- **文件操作函数**：处理文件上传、移动等
- **压缩/解压库**：ZipArchive、PharData
- **系统命令调用**：处理7Z、RAR格式
- **会话管理**：用户认证和状态保持
- **JSON响应**：AJAX请求返回数据

### 安全技术
- **路径遍历防护**：`fm_is_safe_path()`函数校验
- **CSRF防护**：Token验证
- **文件类型限制**：禁止上传可执行文件
- **权限控制**：用户认证后才能操作
- **输入过滤**：清理用户输入

## 技术亮点

1. **SPA架构**：无刷新操作，用户体验好
2. **完整功能**：涵盖文件管理各方面需求
3. **安全性**：多层安全防护
4. **响应式设计**：适配桌面和移动端
5. **可扩展性**：模块化设计，易于添加新功能
6. **用户体验**：键盘快捷键、拖拽操作、进度提示等
